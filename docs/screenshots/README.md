# Screenshot provenance

Captured from the running Realmwatch dashboard using entirely synthetic data:
Northern Realm / ExampleWorld, Coastal Realm / CoastalExample, invented player
names and invented portal coordinates. No production data, credentials, real
player identifiers or world-save files were used.

- overview.png: dashboard summary and example server cards.
- portal-atlas.png: world edge, illustrative biome caps and a filtered,
  highlighted Harbour portal pair.

The underlying interface, icons and map illustrations were initially
AI-generated using OpenAI Codex under human direction, as disclosed in the
project README. These are captures of the interface, not image-generated mockups.
Screenshots are distributed under the project's MIT licence.
